# Testimonials Grid Section

This is my solution to the [Testimonials Grid Section challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/testimonials-grid-section-Nnw6J7Un7).

The goal of this project was to recreate a responsive testimonials section using HTML and CSS, focusing on CSS Grid, card layouts, and maintaining visual consistency across different screen sizes.

![Testimonials Grid Section Preview](./preview.jpg)

## Overview

### Features

- Responsive layout for desktop and mobile devices
- Five testimonial cards with different sizes and background colors
- CSS Grid-based layout
- User profile pictures and testimonial information
- Consistent typography, spacing, and card styling
- Decorative elements and custom fonts

## What I Learned

Working on this project helped me strengthen my CSS layout skills and gain more experience creating responsive interfaces with complex card arrangements.

**CSS Grid**

I practiced using CSS Grid to create a layout with cards of different sizes and positions. This helped me better understand how to organize content within grid rows and columns.

**Responsive Design**

I improved my ability to adapt layouts for different screen sizes and create a comfortable reading experience on both desktop and mobile devices.

**CSS Flexbox**

I practiced using Flexbox to align profile pictures and user information within testimonial cards.

**BEM Methodology**

I gained more experience organizing CSS classes using the Block Element Modifier (BEM) naming convention, making the code easier to read and maintain.

**Typography and Visual Hierarchy**

I learned how to create visual hierarchy by combining font sizes, weights, colors, and spacing to highlight important information.

**Working with Design References**

I improved my attention to detail by recreating the provided design and working with card dimensions, spacing, backgrounds, and alignment.
